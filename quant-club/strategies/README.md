# strategies/

Member strategy work. One folder per person or per project.

Two rules:

1. Commit `.py`, not `.ipynb` (see [`../docs/notebooks.md`](../docs/notebooks.md)).
2. Anything reusable — an indicator, a data helper, a metric — belongs in `tudquant/`, not copy-pasted between folders. Open an issue and we move it.

A backtest result without the data quality report that produced it is not a result.
